# Ubiquitous Language

## Terms

**Weave Engine** - The name of the IPaaS platform.

**Weave** - A workflow definition describing the nodes to execute and the rules connecting them.

**Trigger** - An integration capability that starts a Weave when an event occurs.

**Action** - An integration capability that Engine can execute as a node within a Weave.

**Node** - A configured executable step within a weave.

**Integration** - A system that connects Weave Engine to another product or API.

**Integration Manifest** - An immutable, versioned JSON document describing the connections, triggers, and actions an integration makes available to weaves.

**Connection** - An organisation owned connection to another platform, this stores the credentials and authorisers used by triggers and actions.
